# 游戏设计

## 一句话

被困在午夜循环里的旅人，靠死亡积累记忆，靠别人留下的残响前进；但残响可能是谎言。

## 设计支柱

所有功能都拿来对照这三条，冲突时砍功能而不是改支柱。

1. **知识即进度**：玩家变强主要靠"知道得更多"，而不是数值变高。道具和货币每轮清零，只有线索跨轮保留。
2. **信任是赌注**：相信一条残响要花信念（每轮 2 点）。信对了省时间，信错了可能会死。玩家能看到点赞数，看不到真假。
3. **失败有意义**：每次死亡都会留下点什么，给自己（记忆碎片），也给别人（残响）。

## 核心循环

1. 醒来：带着之前学到的线索，从镇口开始新的一轮
2. 探索：在横版场景里移动，与人物和物件互动
3. 抉择：互动会花钱、用掉道具、得到线索，或通往别的场景
4. 残响：场景里飘过别人的残响，可以相信（花信念）或点赞
5. 死亡或坏结局：得到记忆碎片，并可以在出事的地方刻下一句残响
6. 回到第 1 步，直到打出真结局

## 选项的"锁"

| 锁 | 说明 | 是否跨轮保留 |
|---|---|---|
| 道具锁 | 需要某个道具（可要求数量，可设为用掉） | 否 |
| 货币锁 | 需要花费一定数量的货币 | 否 |
| 知识锁 | 不知道某条线索时，这个选项不会出现 | 是 |
| 软提示 | 知道某条线索的玩家会被提示更该选它 | 是 |

一个选项可以设为"一次性"：每轮只能做一次，做完后从场景里消失。

## 残响规则

- 预设残响由设计者写，标注真假和点赞数；玩家只看到点赞数。
- 玩家在死亡后可以在最后做选择的地方刻一句残响，内容是"别这么做"或"就这么做"。真假由那个选项的实际后果自动判定。
- 点赞数越高的残响越容易被推送，也更容易被相信。这意味着高赞的谎言可以坑很多人，这是设计意图。

## 示例剧情：雾镇 · 第一夜

真相：修女艾格尼丝每晚从地窖走上钟楼敲钟。叫出她的名字，循环才会结束。

三条主要路线：

- **知识线**：在教堂被神父锁进告解室，得知"神父不是敲钟人"；下一轮对神父说出来，拿到蜡烛。
- **道具线**：在教堂翻祷告书拿到铜钥匙，直接打开钟楼大门。
- **金钱线**：在酒馆打工、在喷泉摸硬币，凑够 5 铜币贿赂守夜人；或买蜡烛走地窖密道。

最终都需要知道修女的名字（地窖墙上，或在钟房死一次）。
