# 剧情数据格式

剧情是一个 JSON 对象，存放在 `stories/` 下，编辑器的"导入 / 导出"用的也是这个格式。读取时先由 `validateStory()` 检查结构（出错会给出中文说明），再由 `normalize()` 给缺失的字段补默认值，所以手写时只需要写用到的字段。

## 剧情

| 字段 | 类型 | 说明 |
|---|---|---|
| `formatVersion` | 数字 | 数据格式版本，当前为 1。比游戏支持的版本新时拒绝读取 |
| `id` | 字符串 | 剧情标识，也是导出文件名，例如 `fog-town` |
| `revision` | 数字 | 剧情的版本号，编辑器每次"下载 JSON 文件"时加一。玩家本机的存档版本号不同时会被新版本替换 |
| `name` | 字符串 | 剧情名，显示在顶栏 |
| `start` | 节点 id | 每轮开始的节点 |
| `currency` | 字符串 | 货币名称，默认"铜币" |
| `startMoney` | 数字 | 每轮开局时的货币数量 |
| `items` | `{id: 名称}` | 道具表 |
| `clues` | `{id: 内容}` | 线索表（跨轮保留的知识） |
| `nodes` | `{id: 节点}` | 全部节点 |
| `layoutV` | 数字 | 地图布局算法版本，低于当前版本时会自动重新排布 |

## 节点

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | 字符串 | 场景名 |
| `type` | `story` `choice` `check` `rest` `death` `ending` | 剧情 / 抉择 / 检定 / 休憩 / 死亡 / 结局 |
| `time` | 数字 | 预计停留秒数，用于估算通关时间 |
| `text` | 字符串 | 进入场景时显示的正文 |
| `options` | 选项数组 | 死亡和结局节点为空 |
| `echoes` | 残响数组 | 这个场景里飘过的残响 |
| `deathClue` | 线索 id | 死亡节点：死前揭示的线索 |
| `ending` | `true` / `bad` | 结局节点：真结局（通关）或坏结局（继续轮回） |
| `x` `y` | 数字 | 节点在地图上的位置 |

## 选项

选项既是剧情的分支，也是场景里可以互动的东西。

| 字段 | 默认 | 说明 |
|---|---|---|
| `text` | | 玩家看到的行动描述 |
| `goto` | | 通向的节点 id；等于当前节点表示"留在原地"的行动 |
| `obj` | `''` | 所属物件名。同一场景里同名的选项合并成一个物件，互动时弹出菜单 |
| `look` | `''` | 物件外观：`door` `person` `item` `sign` `orb`；留空按文字自动判断 |
| `pos` | `''` | 物件在场景中的横向位置（3–97，百分比）；留空自动均分 |
| `needItem` / `needQty` / `useItem` | `''` / 1 / false | 道具锁：需要几个某道具，是否用掉 |
| `costMoney` | 0 | 花费的货币 |
| `needClue` | `''` | 知识锁：不知道这条线索时选项不出现 |
| `hintClue` | `''` | 软提示：知道这条线索时提示玩家 |
| `gainItem` / `gainQty` | `''` / 1 | 获得道具及数量 |
| `gainMoney` | 0 | 获得的货币 |
| `gainClue` | `''` | 获得的线索 |
| `once` | false | 每轮只能做一次，做完从场景中消失 |

## 残响

| 字段 | 说明 |
|---|---|
| `id` | 唯一 id，用于点赞 |
| `text` | 残响内容 |
| `target` | 针对的选项序号，`-1` 表示不针对 |
| `kind` | `go` 推荐 / `avoid` 警告 |
| `honest` | 是否真话。只给设计者和模拟器看，玩家看不到 |
| `teach` | 相信后获得的线索 id |
| `likes` | 点赞数 |
| `by` | `preset` 设计者预设 / `play` 玩家留下 |
