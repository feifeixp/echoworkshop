# 字体

两个文件都是子集，由 `scripts/build-fonts.py` 生成，剧情或界面文字改了以后重新生成。

| 文件 | 来源 | 用途 | 许可 |
|---|---|---|---|
| `body.otf` | 思源宋体 Noto Serif CJK SC（[notofonts/noto-cjk](https://github.com/notofonts/noto-cjk)） | 正文、界面。保留 GB2312 全部汉字和游戏里用到的所有字 | SIL Open Font License 1.1 |
| `display.ttf` | 霞鹜文楷 LXGW WenKai（[lxgw/LxgwWenKai](https://github.com/lxgw/LxgwWenKai)） | 标题、场景名、结局大字 | SIL Open Font License 1.1 |

OFL 允许随游戏一起分发和修改（包括生成子集），但不能单独售卖字体本身。发布游戏时，在致谢或关于页面里注明这两个字体。
